# eMART Multi Vendor Marketplace

Laravel multi-vendor marketplace built from scratch in Ubuntu with client and seller areas, custom auth, compounded product filters and with SEO-friendly product page.

**Live demo:** [emart.click](https://emart.click)

## Stack

HTML, SASS, JavaScript, jQuery, AJAX, Laravel, PHP, Blade, MySQL

## Features

- Built solo a marketplace with 30+ Blade pages, client and seller areas, and custom authentication, modeled on eMAG’s UX and developed on Ubuntu.
- Implemented category pages and reviews sections with compounded filters and live counts, favorites, cart, one-page checkout that splits orders per seller and delivery type and fully dynamic returns flow.
- Built most page content dynamically with jQuery and Ajax over a MySQL back-end, with skeleton loading states; key product content is server-rendered in Blade for SEO and first paint.
- Optimized images and loading time (lazy loading with eager, high-priority above-the-fold rows, ImageMagick thumbnails of about 5-10 KB): 100 SEO and 85-90 Performance in Lighthouse (local production build).
